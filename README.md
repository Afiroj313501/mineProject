## 3. 🕵️ Multimodal Deepfake Detection

**Audio and Video Deepfake Detection — Human in the Loop**

A research-focused deepfake detection system designed to analyze manipulated media using multimodal audio and video information while incorporating human decision-making.

### Key Features

- 🎥 Video deepfake detection
- 🔊 Audio analysis
- 🧠 Multimodal analysis
- 👤 Human-in-the-loop decision making
- 🤖 AI-assisted detection
- 📊 Model evaluation
- 📈 ROC-AUC analysis
- 🎯 Recall and accuracy evaluation
- 📋 Human perception study
- 🔬 Research-oriented experimentation

### Research Metrics

- Dataset expanded to **820 videos**
- Accuracy improved from **68.36% → 86.0%**
- ROC-AUC improved from **0.723 → 0.88**
- Fake Recall improved from **56.0% → 84.0%**
- Human unaided accuracy: **58.8%**
- Human + AI agreement: **85.1%**

### Research Areas

- Deepfake Detection
- Computer Vision
- Audio Analysis
- Multimodal AI
- Human-in-the-Loop AI
- AI-Assisted Decision Making
