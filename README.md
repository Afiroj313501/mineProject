# ⭐ Featured Projects

## 1. ResearchPilot AI

**AI-Powered Research Assistant**

- **Repository:** https://github.com/Afiroj313501/ResearchPilot
- **Live Demo:** https://research-pilot-orcin.vercel.app
- **Category:** AI / RAG / Full Stack
- **Status:** Backend Complete | Frontend Development

ResearchPilot AI is an AI-powered research assistant that allows users to upload research papers, organize documents into collections, perform semantic search, and ask citation-grounded questions using Retrieval-Augmented Generation (RAG).

### Features

- User registration and login
- JWT authentication
- Protected routes
- Research collection management
- PDF upload and text extraction
- Automatic document chunking
- Gemini-powered embeddings
- PostgreSQL + pgvector semantic search
- Retrieval-Augmented Generation
- Citation-grounded answers
- Source retrieval
- AI-powered research chat

### Tech Stack

- React
- Vite
- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Supabase
- pgvector
- Prisma ORM
- Google Gemini API
- JWT
- REST API
